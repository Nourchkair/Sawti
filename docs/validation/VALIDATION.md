### Full-suite test history

`env -u CI -u E2E_ENABLED -u RUN_QUALITY_TESTS -u RUN_SPEAKER_BACKTEST -u RUN_NEMOTRON_DRIFT -u WHISPERKIT_MODEL -u QUALITY_RESULTS_PATH -u QUALITY_BASELINE_PATH -u MEETINGTRANSCRIBER_LOCALVQE_MODEL ./scripts/test-isolated.sh` discovered 3,454 app tests and exited 1. Failures included Keychain-backed settings tests, live-caption tests that tried to load Silero VAD, and WhisperKit tests that expected a local model. The test log shows FluidAudio attempted model downloads under the disposable test home; downloads were truncated and failed. The IPC metadata guard emitted no failure, and the wrapper removed its temporary home.

The run also exposed that inherited Keychain tests used the production `com.meetingtranscriber` service. One test calls `delete` on a fixed test account before saving; the Security.framework result from that deletion is ignored, so the log cannot establish whether a pre-existing item was removed. No keychain contents were inspected. XCTest now routes `KeychainHelper` through an in-memory store.

A subsequent 3,454-test isolated run reached completion but failed one host-cache probe (`WhisperKitLocalSnapshotTests.testProductionLocatesARealFetchedModel`). That test enumerated model-cache directory entries and checked file existence, but did not read model contents; `HubApiWrapper` resolves its model cache independently of `AppPaths`, so the test can inspect a host cache despite `SAWTI_TEST_HOME`. It is now gated in isolated runs while CI keeps its pre-warmed cache coverage. A later full run reached the final test and exposed another ungated model-loading case (`WatchLoopE2ETests.testEmptyTranscriptTransitionsToError`); that run was stopped before completion while the test was still running. Review also found the real FluidAudio live-transcription test would load Parakeet and Silero VAD. These cases now use an isolated-run-only model gate, preserving the existing CI model-test behavior. A focused 78-test keychain, cache-gate and model-gate group passed after these changes.

The final isolated invocation on 2026-10-19 discovered 3,456 tests and exited 0. `ModelPreloadTests` were excluded by the wrapper, and tests that initialize real WhisperKit, Parakeet or Silero VAD models were skipped unless explicitly opted in. The wrapper's post-run IPC metadata comparison passed and its temporary test home was removed. This is a clean unit/integration-suite result; it does not validate model inference, real audio capture, microphone/system-audio permissions, or the app bundle.

`env GIT_TERMINAL_PROMPT=0 swift build --disable-keychain --disable-automatic-resolution` passed. The linked `.build/debug/MeetingTranscriber` is an arm64 Mach-O executable, and `otool -l` reports `minos 14.0` / `sdk 14.0`. All attempts were terminated before app compilation; no password was entered and no keychain settings were changed. This was a package-download credential lookup, distinct from code signing. The Xcode app/test integration remains unverified; the SwiftPM executable build succeeded with keychain lookup disabled.

`git diff --check` and `bash -n scripts/test-isolated.sh` passed. `./scripts/lint.sh` could not run because `swiftformat` and `swiftlint` are not installed. ## Evidence rules

- Store only disposable test signals/recordings under an explicit temporary Sawti probe root. Never copy from `~/Library/Application Support/MeetingTranscriber`, Nour's personal recordings or AcademiaOS.
- Record bundle identifier, signing identity/designated requirement, process ancestry, permission state, OS/build, channel configuration, saved file hashes and frame counts with each capture attempt.
- A granted TCC entry, successful `start()` return or zero application error is not proof of audio delivery. Analyze the bytes written by the helper and a known marker in each required source.
- A blocked startup/stop test passes only when the UI remains responsive, the unaffected channel persists independently and the declared supervisor policy actually terminates or latches the failed helper.
- Do not run inherited suite/E2E scripts until P1.2 has isolated defaults, HOME, test file roots and permission access. For the first safe baseline, record exact command, toolchain, environment and whether any test was skipped.
