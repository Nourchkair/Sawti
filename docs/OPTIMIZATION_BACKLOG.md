# Sawti optimization and release-qualification backlog

This backlog records follow-up work deliberately deferred while Beta focuses on complete audio capture, preserving original transcripts, local transcription, and recovery. “Observed” values are measurements from this development machine; they are not promises for other Mac models. Items marked as a release gate must be closed before a public 1.0 claim, even when they do not prevent internal development.

## Upstream changes reviewed for this backlog

- [#523](https://github.com/pasrom/meeting-transcriber/pull/523) and [#525](https://github.com/pasrom/meeting-transcriber/pull/525) add consent-gated Chromium/WebRTC browser detection and a local-tone capture-proof lane. These mechanisms and tests are already in the inherited source. They prove a synthetic browser route only, not Google Meet-specific tab isolation.
- [#610](https://github.com/pasrom/meeting-transcriber/pull/610) and [#612](https://github.com/pasrom/meeting-transcriber/pull/612) correct browser-process identity and replace a fixed Chromium allowlist with assertion-based matching. These are already reflected in the source and regression tests.
- [#456](https://github.com/pasrom/meeting-transcriber/pull/456), which proposed making ScreenCaptureKit the default to address Teams/Zoom silence, was closed. The upstream maintainer rejected the broad default because it increases permission scope, captures system mix rather than only the requested app, and regresses existing live/capture behavior. Its per-track non-silence guard landed separately in [#574](https://github.com/pasrom/meeting-transcriber/pull/574). Sawti keeps scoped process taps as the default and tests for silent tracks.
- [#772](https://github.com/pasrom/meeting-transcriber/pull/772) adds an opt-in app-audio zero-track watchdog. Keep its existing default and bounds until live Sawti evidence justifies a change.
- [#713](https://github.com/pasrom/meeting-transcriber/pull/713) and [#675](https://github.com/pasrom/meeting-transcriber/pull/675) remain open; [#789](https://github.com/pasrom/meeting-transcriber/pull/789) remains a draft, as checked on 2026-10-19. They are proposals, not merged fixes. The #789 discussion identifies a remaining partial-write gap-fill risk, and #675's discussion flags a separate macOS 14 BNNS crash. Check the current source and all supported OS versions before adopting any of them.
- The upstream issue tracker is enabled and was reviewed on 2026-10-19. Open reports relevant to Beta include [#699](https://github.com/pasrom/meeting-transcriber/issues/699), [#712](https://github.com/pasrom/meeting-transcriber/issues/712), [#724](https://github.com/pasrom/meeting-transcriber/issues/724), [#765](https://github.com/pasrom/meeting-transcriber/issues/765), [#778](https://github.com/pasrom/meeting-transcriber/issues/778), [#790](https://github.com/pasrom/meeting-transcriber/issues/790), and [#791](https://github.com/pasrom/meeting-transcriber/issues/791). The issue tracker can change; recheck before release.
